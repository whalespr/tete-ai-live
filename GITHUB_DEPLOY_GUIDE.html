Tip: Keep this guide open in one tab and do the clicks in another tab side-by-side.

1 Create your GitHub account

GitHub is where your website's files will live. It's free.

  1. Go to github.com → click Sign up (top right).
  2. Enter your email, create a password, pick a username (e.g. tete-ai), and verify you're human.
  3. GitHub will email you a code — paste it to confirm.
  4. When it asks "What do you want to do?" — just click Continue / Skip until you're on your dashboard (you'll see a dark header with your avatar).
✅Done when: you see your GitHub dashboard and your profile picture in the top-right corner.

2 Create a new repository (your website's folder on GitHub)

  1. On GitHub, click the + ▾ in the top-right → New repository.
  2. Repository name: type tete-ai-live (exactly like that).
  3. Description (optional): TETE AI — live draw predictions
  4. Choose Public (needed for free Vercel deploy — your API keys will not be in the files, so this is safe).
  5. Do NOT tick "Add a README" — leave it unchecked.
  6. Click Create repository.
What you'll see next
  • A page titled Quick setup — if you've done this kind of thing before
  • A link that says uploading an existing file — that's what you click next.
⚠️Common mistake: Don't create a README here — you'll upload your own files in the next step. If you already ticked it, delete the repo and start this step again.

3 Upload your tete-ai-live folder (drag & drop — no git needed)

This is the easiest way — no terminal, no commands.

3A — Click the upload link

  1. On the empty repo page, click the blue link uploading an existing file (under "Quick setup").

3B — Drag your files in

  1. Open your file explorer and find the tete-ai-live folder you downloaded from this chat. Open it so you see index.html, api folder, vercel.json, etc.
  2. Select everything inside the tete-ai-live folder — click one file, press Ctrl + A (Windows) or Cmd + A (Mac), so all files are highlighted.
  3. Drag them onto the GitHub upload page — you'll see a dashed box that says Drag files here. Drop them. GitHub will list them: index.html, api/predictions.js, vercel.json, package.json, README.md, etc.
⚠️Important: Drag the contents of the folder, not the folder itself. GitHub should show index.html at the top level, not a nested tete-ai-live/index.html. If you see a folder inside, remove it and drag the inner files instead.

3C — Commit (save) the upload

  1. Scroll down, you'll see a box "Commit changes". Leave the message as Add files via upload.
  2. Click Commit changes.
✅Done when: your repo page now shows the file list — index.html at the top, plus the api folder. Refresh the page if you don't see them.
What success looks like
  • Repo URL is github.com/YOUR-USERNAME/tete-ai-live
  • Files visible: index.html, api/predictions.js, vercel.json, package.json
  • Copy your repo URL from the address bar — you'll paste it into Vercel next.

4 Create your Vercel account (where your site goes live)

Vercel turns your GitHub files into a real website with a real URL. Free tier is plenty.

  1. Go to vercel.com → click Sign Up.
  2. Choose Continue with GitHub — this links Vercel to GitHub so it can read your repo. Click Authorize Vercel when GitHub asks.
  3. Vercel will ask a couple of setup questions — accept defaults, click Continue.
✅Done when: you're on the Vercel dashboard — a dark page with a big Add New → Project button.

5 Import your repo and Deploy (one click)

  1. On Vercel dashboard, click Add New ▾ → Project.
  2. You'll see your GitHub repo tete-ai-live in the list. Click Import next to it.
    Don't see it? Click Adjust GitHub App Permissions → allow access to tete-ai-live → go back.
  3. On the "Configure Project" page: leave everything as-is. Framework says Other — that's correct. Don't change it.
  4. Click Deploy. Vercel will build your site — you'll see a spinner for ~30–60 seconds, then confetti.
What you'll see
  • A page saying Congratulations! with a screenshot of your site.
  • A live URL like https://tete-ai-live.vercel.app — click it. Your draw predictions are live!
  • There's also a Visit button. Your site is already on the internet.
ℹ️At this point the site shows demo fixtures — that's normal. Real bookmaker odds come in the next step. You already have a live website.

6 Add your 2 free API keys to go live (2 minutes)

Without keys the site shows realistic sample matches. With keys it pulls real odds from 6 bookmakers every day. Both keys are free.

6A — Get the keys

Key 1 — The Odds API
500 requests/month free
  1. Go to the-odds-api.com → Get API Key / Sign Up
  2. Enter email + password → confirm email.
  3. Dashboard shows your API Key — a long string like 8f3a2c…. Copy it.
Key 2 — API-Football (optional but recommended)
100 requests/day free — for deeper history
  1. Go to api-football.com → Get Started → it takes you to api-sports.io
  2. Sign up → Dashboard → copy your API Key.
  3. Note: host is v3.football.api-sports.io

6B — Paste them into Vercel (they stay secret, never shown to visitors)

  1. In Vercel, open your project (tete-ai-live) → top bar click Settings → left sidebar click Environment Variables.
  2. Add 3 variables — click Add for each one:
    ODDS_API_KEY = (paste your The Odds API key) API_FOOTBALL_KEY = (paste your API-Football key) API_FOOTBALL_HOST = v3.football.api-sports.io
    For each: leave Environment as Production (and tick Preview + Development too if you want). Click Save.
  3. Go to Deployments (top bar) → click the ⋯ on the latest deployment → Redeploy → tick "Use existing Build Cache" OFF → Redeploy.
    This rebuilds with your keys baked in server-side. Takes ~45 seconds.
🔒Security: Environment Variables in Vercel are never visible to visitors — they live only on the server. Your repo on GitHub stays clean. Never paste keys into index.html.
✅Done when: after redeploy, visiting your Vercel URL shows LIVE — real bookmaker odds in the top bar / banner instead of DEMO.

7 Check it works

  1. Open your Vercel URL (e.g. https://tete-ai-live.vercel.app).
  2. You should see: hero with KPIs, Draw Picks cards, All Matches table, Bookmaker Odds, How It Works.
  3. Click ↻ Refresh — it re-scores. Try the league filter and ★ Bankers pill.
  4. Test the API directly: visit https://YOUR-SITE.vercel.app/api/predictions — you should get JSON with mode: "live" (or mode: "demo" if keys aren't set yet).
If you still see DEMO after adding keys
  • Check Vercel → Settings → Environment Variables → that ODDS_API_KEY is set for Production (not just Preview).
  • Did you click Redeploy after saving? The old build doesn't have the new keys.
  • Check The Odds API dashboard — you have 500 free credits/month. One refresh uses ~8 credits (8 leagues). Don't spam Refresh.
  • Visit /api/predictions — if it says mode:"demo", the key wasn't read. Double-check for extra spaces.
ℹ️Auto-updates are already wired: Vercel Cron hits /api/predictions?warm=1 daily at 07:00 UTC and caching is s-maxage=3600, so visitors always get fast, fresh picks without you doing anything.

8 Add your own domain like tete-ai.com (optional)

  1. Buy a domain if you don't have one — Namecheap, Google Domains, or Cloudflare Registrar all work. Search for tete-ai.com (or whatever you want) and check out.
  2. In Vercel → Project → Settings → Domains → type your domain (e.g. tete-ai.com) → click Add.
  3. Vercel shows you DNS records to add — usually a CNAME or A record. Copy them.
  4. Go to your domain registrar → DNS settings → add the records Vercel gave you. Save.
  5. Wait 5–60 minutes for DNS to propagate. Vercel auto-provisions HTTPS — you'll see a green tick when it's live.
✅Done when: visiting https://tete-ai.com shows your site with a padlock (HTTPS).

Vercel's Domains page shows status — if it says "Pending" or "Invalid Configuration", double-check the DNS records and give it a bit more time.
